# Report_Extraction

## 1. 业务背景

### 1.1 矿产品贸易简介

矿产品国际贸易是一个涉及矿山开采、贸易商、冶炼厂、船运公司、第三方检验机构和海关等多方参与的复杂业务。一笔典型的贸易流程大致如下：

卖方（矿山/贸易商）将矿产品从装货港装船，运往买方（冶炼厂/贸易商）指定的卸货港。货物到港后，需要由第三方检验机构对货物的重量和品质进行检验，以确定最终的结算价格。

在这个过程中，会产生大量的检验报告、化验证书、品质证书等文档。这些文档是贸易结算的核心依据，其中的数据需要被准确提取并录入业务系统。

### 1.2 主要商品类型

本系统目前覆盖的主要矿产品类型包括：

- **铜精矿（Copper Concentrates）**：由铜矿石经选矿后得到的精矿粉末，铜含量通常在20%-30%。贸易中的计价元素主要是铜（Cu）、金（Au）、银（Ag），同时需关注砷（As）、氟（F）等杂质元素，因为超标会被罚款。

- **铁矿石（Iron Ore）**：分为块矿（Lump）和粉矿（Fines）。计价元素为全铁（TFe），杂质元素包括二氧化硅（SiO₂）、三氧化二铝（Al₂O₃）、硫（S）、磷（P）等。粒度分布也是重要的品质指标。

- **镍铁/镍生铁（Ferro Nickel / Nickel Pig Iron）**：含镍铁合金，计价元素为镍（Ni），杂质元素包括硅（Si）、碳（C）、硫（S）、磷（P）、铬（Cr）等。镍铁通常指印尼/新喀产铸锭，镍生铁通常指中国/印尼产的低品位含镍铁合金。

### 1.3 检验报告的类型

在一笔贸易中，通常会产生以下几类检验报告：

- CIQ品质证书/重量证书：中国海关出入境检验检疫机构出具，是进口货物通关的必要文件。品质证书包含化学成分检测结果，重量证书包含水尺计重或秤重结果。

- 第三方检验报告：由独立的国际检验机构（如 Intertek、SGS、Bureau Veritas、CCIC 等）出具。可能是仅含品质的化验证书，也可能是同时包含重量和品质的综合检验报告（Inspection Report）。

- 卖方化验报告：由矿山或生产商自行化验后出具，如 PT Freeport 的 Assay Submittal。

- 买方化验报告：由买方或其委托的冶炼厂化验后出具。

- 仲裁化验报告：当买卖双方的化验结果存在差异且超过合同约定的允许范围时，由双方共同选定的独立实验室进行仲裁检测，其结果作为最终结算依据。

- 品质交换意见书：买卖双方交换各自的化验结果，用于比对和协商。

- 贸易商证书：由贸易商（如 Trafigura、Glencore）出具的品质证书。

### 1.4 核心业务概念

#### Lot（批次）

一船货物通常会被分成多个 Lot（批次）进行取样和化验。每个 Lot 是一个独立的计价单元，有自己的重量和化验结果。例如一船 5000 吨的铜精矿可能被分成22个 Lot，每个 Lot 约 200-500 吨。

#### Sub-lot（子批次）

部分报告中，一个 Lot 下还会细分为多个 Sub-lot。典型场景是镍铁检验报告：一个大批次 P1 下可能有7个子批次 P1-1 到 P1-7，每个子批次有独立的镍含量检测结果，然后加权平均得到 P1 整体的镍含量。

#### Composite（混合样）

某些元素（特别是杂质元素）不会逐 Lot 检测，而是将所有 Lot 的样品混合后统一检测，这就是 Composite（混合样）。例如铜精矿中的砷（As）含量通常只报告一个全船的 Composite 值。

#### 计价元素与杂质元素

- 计价元素（Payable Elements）：买方需要为之付款的有价元素，如铜精矿中的铜、金、银。这些元素会逐 Lot 检测，因为它们直接影响每个 Lot 的结算金额。

- 杂质元素（Penalty Elements）：超过合同约定限值时会被罚款的有害元素，如铜精矿中的砷（As）、氟（F）等。这些元素通常只在 Composite 级别检测。

#### DMT 与 WMT

- DMT（Dry Metric Ton，干吨）：去除所有水分后的货物重量，是贸易结算的基础。

- WMT（Wet Metric Ton，湿吨）：含水分的货物重量。计算公式：`WMT × (1 - 水分%) = DMT`。

### 1.5 本功能的作用

本功能使用AI视觉大模型自动读取上述各类检验报告（PDF文件），将其中的关键信息提取为统一的JSON格式结构化数据。提取结果可直接导入业务系统，替代人工录入，大幅提高效率并减少错误。
