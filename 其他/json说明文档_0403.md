## 1. report — 报告元信息

描述这份报告本身的基本属性：是谁出的、什么时候出的、什么类型。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `report_id` | string | **报告编号**。报告的主要唯一标识，通常印在报告抬头或右上角。不同机构的编号命名规则不同。 | `"BCC10072S"`, `"MIN260100148NC"`, `"K22-070096"` |
| `report_number` | string | **报告流水号**。部分机构除了主编号外还有内部流水号，作为辅助标识。如果报告只有一个编号，此字段为 null。 | `"RMIN2600595"`, `"LSI 6846 - 58999"` |
| `report_date` | string | **报告签发日期**。格式为 YYYY-MM-DD。即报告正式出具并盖章的日期，不是检验日期。 | `"2022-01-25"`, `"2026-02-03"` |
| `report_type` | string | **报告类型**。标识这份报告在贸易流程中的角色。详见[附录A](#附录areport_type-报告类型枚举值说明)。 | `"umpire_assay"`, `"seller_assay"` |
| `issuing_organization` | string | **出具机构全称**。出具该报告的检验/化验机构的完整名称。 | `"Intertek Testing Services Ltd., Shanghai"` |
| `issuing_organization_short` | string | **出具机构简称**。行业内常用的缩写，方便快速识别。 | `"Intertek"`, `"CCIC"`, `"BV"`, `"AHK"`, `"BGRIMM"` |
| `inspection_standard` | array | **检验标准列表**。该报告依据的国家标准、国际标准或行业标准。 | `["GB/T 6730.65-2009", "ISO 3087:2020"]` |
| `analysis_methods` | object | **各元素的分析方法**。键为元素符号，值为对应的分析方法编号或描述。并非所有报告都会注明方法。 | `{"Cu": "W0700 - Volumetric", "Au": "W0701 - Fire Assay Gravimetric"}` |

## 2. trade — 贸易信息

描述这笔贸易的参与方和物流信息：谁买的、谁卖的、用什么船、从哪到哪。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `buyer` | string | **买方/收货人/委托方**。报告中的 Consignee、Client、Applicant、收货人等角色。在仲裁报告中可能列出买卖双方。 | `"五矿有色金属股份有限公司"`, `"IXM S.A."` |
| `seller` | string | **卖方/发货人**。报告中的 Consignor、Seller 等角色。化验报告中经常缺失此字段。 | `"MINMETALS CHEERGLORY LIMITED"`, `"PT Freeport Indonesia"` |
| `contract_no` | string | **合同号**。买卖双方签订的贸易合同编号，是关联同一笔交易多份报告的关键字段。 | `"2024AU010J110G0"`, `"22FLATS2603YX"` |
| `invoice_no` | string | **发票号**。商业发票编号，通常出现在CIQ证书中。 | `"24ZINVI052"` |
| `bl_no` | string | **提单号**（Bill of Lading No.）。海运提单编号，是追踪货物运输的关键单据号。 | `"SN80250524016"` |
| `client_ref` | string | **客户参考号**。委托方内部的业务编号或合同参考号，不同于正式合同号。 | `"BCC10072S"`, `"26CNMIS7202TGXH01F"` |
| `vessel` | string | **船名**。承运货物的船舶名称。 | `"CITIUS"`, `"APL ESPLANADE"`, `"UNITY"` |
| `voyage_no` | string | **航次号**。同一艘船的不同航次编号。 | `"578002505240"` |
| `loadport` | string | **装货港**。货物从哪个港口装船。 | `"Dampier, Australia"`, `"Amamapare, Indonesia"` |
| `discharge_port` | string | **卸货港**。货物在哪个港口卸载。 | `"黄岛 Huangdao"`, `"Fangcheng, China"` |
| `arrival_date` | string | **到货日期**。船舶抵达卸货港的日期，格式 YYYY-MM-DD。 | `"2024-11-12"` |
| `completion_of_discharge_date` | string | **卸货完成日期**。货物全部从船上卸完的日期。 | `"2024-11-13"` |
| `inspection_date` | string | **检验日期**。进行取样和/或化验的日期范围。 | `"2026-01-16 to 2026-01-18"` |
| `sampling_dates` | string | **取样日期**。从货物中采集代表性样品的日期范围。取样是化验的前置步骤。 | `"12/08/21 - 18/08/21"` |

## 3. cargo — 货物信息

描述被检验的货物本身是什么。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `commodity` | string | **商品大类**。标准化的商品类型代码，用于系统分类。详见[附录B](#附录bcommodity-商品类型枚举值说明)。 | `"copper_concentrates"`, `"iron_ore_lump"` |
| `commodity_name` | string | **商品名称原文**。从报告中直接摘录的商品描述，保留原始中英文。 | `"铁矿块 IRON ORE LUMP"`, `"Ferro Nickel"` |
| `quality_name` | string | **品质/品牌名称**。矿产品的矿山来源或品牌标识，在铜精矿贸易中尤为重要，不同矿山的精矿品质差异很大，直接影响定价。 | `"Grasberg"`, `"Constancia"`, `"Red Chris"`, `"Aranzazu"`, `"SP10F"` |
| `declared_quantity` | number | **申报数量**。贸易单据上声明的货物数量（数值部分）。 | `3000`, `76206658`, `224.995` |
| `declared_quantity_unit` | string | **申报数量单位**。 | `"MT"` (公吨), `"KG"` (千克), `"DMT"` (干公吨) |
| `packing` | string | **包装方式**。矿产品通常为散装。 | `"In bulk"` (散装) |

## 4. weight — 重量信息

描述货物的实际称重结果。只有部分报告包含重量数据（如CIQ重量证书、Inspection Report）。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `has_weight_data` | boolean | **是否包含重量数据**。快速标识该报告是否有称重信息，方便程序判断。 | `true`, `false` |
| `bl_weight_mt` | number | **提单重量**（公吨）。提单上记载的货物重量，通常由装港确定，是贸易的初始重量依据。 | `70717` |
| `total_wet_weight_mt` | number | **总湿重**（公吨）。含水分的货物总重量。 | `80096` |
| `total_dry_weight_mt` | number | **总干重/净干重**（公吨）。扣除水分后的货物净重，是结算的关键依据。 | `2855.311`, `76764.0` |
| `moisture_at_discharge_pct` | number | **卸货时水分**（%）。卸货时测定的货物含水率。 | `4.16` |
| `moisture_deduction_mt` | number | **水分扣除量**（公吨）。因含水率而从湿重中扣除的重量。 | `3332.0`, `5.973` |
| `weighing_method` | string | **称重方式**。描述如何测定货物重量的方法。 | `"draft survey"` (水尺计重), `"bridge scale"` (地磅称重) |

### 4.1 lot_weights — 各批次的重量明细

当货物分批次称重时，记录每个批次的详细重量数据。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `lot_id` | string | **批次编号**。 | `"P1"`, `"P2"` |
| `gross_weight_mt` | number | **毛重**（公吨）。装载货物的运输工具（卡车/车皮）的总重量。 | `1356.920` |
| `tare_weight_mt` | number | **皮重**（公吨）。空载运输工具的重量。 | `507.280` |
| `impurities_mt` | number | **杂质重量**（公吨）。运输过程中混入的非货物杂质的重量。 | `7.630` |
| `moisture_mt` | number | **水分重量**（公吨）。该批次扣除的水分重量。 | `2.358` |
| `net_weight_mt` | number | **净重**（公吨）。毛重 - 皮重 - 杂质 - 水分 = 净重。 | `839.652` |

## 5. assay — 化验/品质数据

这是整份报告**最核心的数据**，记录了货物的化学成分分析结果。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `analysis_state` | string | **分析基准**。化验结果是以干基还是原样计算的。绝大多数报告为干基。 | `"dry_basis"` (干基，扣除水分后), `"as_received"` (原样，含水分) |

### 5.1 lot_data — 批次级化验数据

每个Lot（批次）的化验结果。**这是结算计价的直接依据。**

> **什么是Lot?** 一船货物通常被分成若干批次（Lot），每个Lot独立取样、独立化验、独立结算。Lot的划分通常基于卸货顺序或仓位。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `lot_id` | string | **批次编号**。不同报告的编号风格不同，保留原始编号。 | `"1"`, `"P1"`, `"lot1"` |
| `lot_weight_wmt` | number | **该Lot湿重**（WMT = Wet Metric Ton），含水分的重量。 | `237.36` |
| `lot_weight_dmt` | number | **该Lot干重**（DMT = Dry Metric Ton），扣除水分后的重量。这是计算金属量的基础。 | `218.490`, `404.907` |
| `moisture_pct` | number | **该Lot水分**（%）。 | `7.95`, `8.84` |
| `elements` | object | **各元素含量**。键为元素符号，值为含量数值和单位。详见[附录C](#附录c常见化学元素符号对照表)。 | 见下方说明 |

**elements 内部结构：**

```json
"elements": {
  "Cu": {"value": 21.22, "unit": "%"},     // 铜含量21.22%
  "Au": {"value": 11.3, "unit": "g/t"},    // 金含量11.3克/吨
  "Ag": {"value": 204, "unit": "g/t"}      // 银含量204克/吨
}
```

- `value`：数值，保留报告原始精度
- `unit`：单位，常见为 `"%"`（百分比）或 `"g/t"`（克/吨，也写作 g/MT, g/1000kg, g/DMT，含义相同）

### 5.2 sub_lots — 子批次级化验数据

部分报告中，一个Lot下面还细分为多个Sub-lot，每个Sub-lot有独立的化验值。

> **什么时候会出现Sub-lot?** 典型场景是镍铁检验：一个大批次（如P1）可能对应几十车货物，每4-5车归为一个Sub-lot独立取样化验。计价元素（Ni）逐Sub-lot检测，而杂质元素只在整个Lot的混合样中检测。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `sub_lot_id` | string | **子批次编号**。通常为"Lot编号-序号"的格式。 | `"P1-1"`, `"P1-2"`, `"P2-5"` |
| `elements` | object | **各元素含量**。结构同上，但通常只包含计价元素。 | `{"Ni": {"value": 13.75, "unit": "%"}}` |

### 5.3 composite_data — 混合样/复合样数据

杂质元素和罚款元素的化验结果，通常在混合样（Composite）级别报告，而非逐Lot报告。

> **什么是Composite?** 将多个Lot的样品按重量比例混合后的代表性样品。杂质元素（如砷As、氟F、汞Hg）含量较低，在Composite级别检测即可满足精度要求，且节省化验成本。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `composite_id` | string | **混合样编号**。可能是全船一个（"Composite"），也可能每个Lot各一个（"Composite P1"）。 | `"Composite"`, `"Composite P1"`, `"Composite P2"` |
| `scope` | string | **覆盖范围**。该混合样对应哪些Lot的货物。 | `"all_lots"` (全船混合), `"P1"` (仅P1批次) |
| `elements` | object | **各杂质元素含量**。结构同上。这些元素通常用于判断是否触发合同中的罚款条款。 | `{"As": {"value": 1.88, "unit": "%"}, "F": {"value": 349, "unit": "ppm"}}` |

### 5.4 weighted_average — 加权平均值

全船货物各元素的加权平均含量，是衡量整船货物整体品质的汇总指标。

> **如何计算?** 加权平均 = Σ(各Lot含量 × 各Lot干重) / Σ(各Lot干重)。即重量大的Lot对平均值影响更大。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `scope` | string | **覆盖范围**。通常为全船。 | `"all_lots"` |
| `weight_basis` | string | **加权基础**。说明该平均值是如何产生的。 | `"calculated"` (计算所得), `"by_dmt"` (按干重加权) |
| `elements` | object | **各元素的加权平均含量**。可同时包含计价元素和杂质元素。 | `{"Ni": {"value": 14.39, "unit": "%"}, "S": {"value": 0.265, "unit": "%"}}` |

## 6. physical_properties — 物理性质

非化学成分的物理指标，主要用于铁矿石。

### 6.1 size_distribution — 粒度分布

铁矿石的颗粒大小分布，影响冶炼效率。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `fraction` | string | **粒度级别描述**。表示筛分条件。 | `"-6.3mm"` (小于6.3mm), `"+40mm"` (大于40mm), `">6.3mm"` |
| `value` | number | **该粒度级别的占比**（%）。 | `8.1`, `1.9`, `14.23` |
| `unit` | string | **单位**。 | `"%"` |
| `standard` | string | **检验标准**。 | `"ISO 4701:2019"` |

## 7. seals — 封签信息

描述样品包装上的封签状态。封签是保证样品在运输过程中未被篡改的重要手段。

> **为什么封签很重要?** 在矿产品贸易中，买卖双方和独立第三方分别在样品袋上加封。化验实验室收到样品时需确认封签完好（intact），如果封签破损（broken），化验结果的法律效力会受到质疑。

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `organization` | string | **封签机构**。加贴封签的公司或检验机构。 | `"CCICGX"`, `"Intertek"`, `"A.H. Knight"` |
| `seal_type` | string | **封签类型**。 | `"Company Sealing Tape"` (封条), `"Company Stamp"` (印章) |
| `status` | string | **封签状态**。 | `"intact"` (完好), `"broken"` (破损) |

## 8. notes — 备注

| 字段 | 类型 | 说明 |
|------|------|------|
| `notes` | string | **重要备注**。报告中的特殊说明、异常情况、免责声明等需要关注的补充信息。 |

常见备注内容包括：
- "DMT values provided by client"（干重由客户提供，非检验机构测定）
- "Hg tested on sample as received"（汞在原样上检测，非干基）
- "Impurity result from random truck checking is referential only"（杂质为随机抽检，仅供参考）

## 附录A：report_type 报告类型枚举值说明

| 枚举值 | 中文名称 | 说明 | 在贸易中的角色 |
|--------|----------|------|--------------|
| `ciq_quality` | CIQ品质证书 | 中国海关出入境检验检疫局出具的品质检验结果 | 进口矿产品清关所需的官方文件 |
| `ciq_weight` | CIQ重量证书 | 中国海关出入境检验检疫局出具的重量鉴定结果 | 进口矿产品清关所需的官方文件 |
| `third_party_quality` | 第三方品质证书 | 独立第三方检验机构（如CCIC、SGS）出具的品质检验结果 | 贸易双方约定的独立品质检验 |
| `third_party_weight` | 第三方重量证书 | 独立第三方出具的重量鉴定结果 | 贸易双方约定的独立重量鉴定 |
| `third_party_inspection` | 第三方综合检验报告 | 同时包含重量和品质信息的综合检验报告 | 如Intertek的Inspection Report |
| `seller_assay` | 卖方化验报告 | 由卖方或卖方委托的实验室出具的化验结果 | 结算流程的起点，卖方提出的品质主张 |
| `buyer_assay` | 买方化验报告 | 由买方或买方委托的实验室出具的化验结果 | 买方对品质的独立验证 |
| `umpire_assay` | 仲裁化验报告 | 当买卖双方化验结果差异超出合同允许范围时，由双方共同认可的第三方仲裁实验室出具 | 品质争议的最终裁决依据 |
| `arbitration` | 仲裁检测报告 | 同上，部分中文报告使用此称呼 | 同umpire_assay |
| `assay_exchange` | 品质交换意见书 | 卖方向买方提交的品质化验结果交换文件 | 结算谈判的起始文件 |
| `certificate_of_analysis` | 分析证书 | 受某一方委托出具的化验结果，不特指买方或卖方 | 需结合上下文判断其角色 |
| `other` | 其他 | 不属于以上任何类型的报告 | — |

## 附录C：常见化学元素符号对照表

### 计价元素

| 符号 | 中文名 | 英文名 | 常见单位 | 说明 |
|------|--------|--------|----------|------|
| Fe | 铁（全铁） | Iron (Total Fe, TFe) | % | 铁矿石的主要计价指标 |
| Cu | 铜 | Copper | % | 铜精矿的主要计价指标 |
| Au | 金 | Gold | g/t | 铜精矿中的副产贵金属，g/t = 克/吨 |

| 单位 | 全称 | 换算关系 |

## 附录D：数据层级关系图解

```
一份报告 (Report)
│
├── 报告元信息 (report)          ← 报告编号、日期、类型、出具机构
├── 贸易信息 (trade)             ← 买卖方、合同号、船名、港口
├── 货物信息 (cargo)             ← 商品类型、品质名称、申报数量
│
├── 重量信息 (weight)            ← 仅部分报告有
│   └── 各批次重量 (lot_weights) ← 毛重、皮重、净重
│
├── 化验数据 (assay)             ← 核心数据
│   │
│   ├── 批次数据 (lot_data)      ← 每个Lot的重量 + 计价元素含量
│   │   ├── Lot 1: Cu=21.22%, Au=11.3g/t, Ag=204g/t
│   │   ├── Lot 2: Cu=21.31%, Au=10.7g/t, Ag=204g/t
│   │   └── ...
│   │   │
│   │   └── [可选] 子批次 (sub_lots)  ← 仅部分商品有
│   │       ├── P1-1: Ni=13.75%
│   │       ├── P1-2: Ni=13.66%
│   │       └── ...
│   │
│   ├── 混合样数据 (composite_data)  ← 杂质元素在此级别报告
│   │   └── As=1.88%, F=349ppm, Hg=1ppm ...
│   │
│   └── 加权平均 (weighted_average)  ← 全船汇总
│       └── Cu=21.27%, Au=11.0g/t ...
│
├── 物理性质 (physical_properties)   ← 粒度等，主要用于铁矿
├── 封签信息 (seals)                 ← 样品封签完好性
└── 备注 (notes)                     ← 特殊说明
```

### 业务流程中各层级数据的用途

| 数据层级 | 业务用途 |
|----------|----------|
| **Lot级计价元素** | 逐Lot结算，计算每个Lot的金属量（DMT × 品位）和对应货款 |
| **Sub-lot级数据** | 了解批次内部品质波动，通常不直接用于结算 |
| **Composite杂质元素** | 判断是否触发合同罚款条款（如 As > 0.5% 则扣款） |
| **加权平均值** | 评估整船货物整体品质，与合同规格比对 |
| **重量数据** | 结算的重量依据，湿重扣水分得到干重 |
| **封签信息** | 确认化验结果的法律有效性 |
